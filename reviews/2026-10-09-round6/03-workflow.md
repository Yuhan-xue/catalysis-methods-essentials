# 验证流程评审

## R6-W01：PDF 比对器对可见变化返回“内容相同”

**优先级／状态**：P2，待修复。

**定位**：`tools/cmp_release_pdf.py:69–93`。逐页只比较规范化文字内容和 `get_drawings()` 的对象数量；前面另检查页数和书签。未比较绘图坐标／样式、栅格图像内容、文字坐标。因此 `IDENTICAL CONTENT` 超出了实际检查能力。

**隔离复现**：本轮脚本在输出目录生成一页 PDF，包含同一行文字、一个矩形、一幅纯色栅格图和一个书签。每个变体只改变一项，其余条件不变。

| 变体 | 比对器退出码／结果 | 相同渲染环境下改变的颜色通道字节数 |
| --- | --- | ---: |
| 只改 metadata 标题 | 0 / IDENTICAL CONTENT | 0 |
| 矩形下移 60 pt，绘图数量不变 | 0 / IDENTICAL CONTENT | 2720 |
| 栅格图由红变绿，位置尺寸不变 | 0 / IDENTICAL CONTENT | 7200 |
| 同一段文字从 y=40 移到 y=220 | 0 / IDENTICAL CONTENT | 4212 |

字节数为同尺寸 pixmap 的颜色分量差异计数，不是不同像素数。元数据变体作为正对照，另外三个变体都是预期应拒绝的可见差异。完整 stdout、退出码和栅格哈希见 [verification.json](verification.json) 的 `comparator`。

**影响**：教材图线位置、显微图片或排版被改变时，比对器仍可能认证“相同”。这削弱了非确定性编译／历史重写后核验附件等流程的可信度。此实验没有证明现有发布附件已损坏，也没有重新验证所有历史 release。

**建议**：先明确工具承诺。若只做结构比较，应返回“结构检查一致，视觉等价未验证”，不得作为内容等价的唯一门禁；若要认证读者看到的内容，需在受控渲染器／字体环境下加入逐页视觉比较，并保留书签、链接等非像素检查。也可比较规范化的对象几何与图像内容，但必须覆盖这三类反例，不能仅扩充对象计数。

**验收**：metadata 对照仍通过；三个视觉变体都不能再返回“内容相同”。若只降级为结构工具，调用它的文档／发布流程必须明确要求另一项视觉证据，并确保单凭结构 PASS 无法宣告内容等价。保留同环境下重复构建、真正文字差异、页数／书签差异等基础样例。
