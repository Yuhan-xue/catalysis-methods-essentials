# 图证说明

两个 PNG 均裁自本仓库发布件 `v0.1.0-pre`，不是重绘或模拟的新图：

- `tpd-detail.png`：PDF 第 68 页，供 C05-02 检查生成函数、图形与图注的对应关系。
- `magic-detail.png`：PDF 第 90 页，供 C08-01 检查转子轴、B0 与角弧。

发布件 SHA-256 见上级目录的 `build-verification.json`。原书扫描页面仅用于本地核对，本审阅目录不再分发原书扫描图。科学结论以源码、原书页码和独立复算为依据，裁图只帮助定位图形问题。

> 说明：本目录此前的原书页面截图（PNG）已移出仓库——它们体积大且是原书页面的位图副本。需要时用 tools/vpage.py 从源 PDF 重新渲染同一页。
