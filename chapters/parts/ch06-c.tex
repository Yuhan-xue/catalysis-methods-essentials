\subsection{拉曼光谱在金属氧化物催化剂中的应用}

\begin{probout}
本节要回答的问题是：\textbf{对一类氧化物催化剂，拉曼光谱能给出哪几类结构信息，这些
信息又怎样与活性、选择性挂钩？}拉曼应用于催化研究始于 20 世纪 70 年代；1970 年代
初 Brown、Makovsky 与 Kees 等研究组把它用于 \ce{gamma-Al2O3} 和
\ce{CoO-MoO3/gamma-Al2O3} 催化剂\src{S1 §6.3，书内 p.356 / PDF p.375}。对过渡金属
氧化物这类烃类选择氧化催化剂，拉曼能给出四类信息：

\begin{itemize}
\item ① 金属氧化物的\textbf{晶相结构}；
\item ② 金属氧化物的\textbf{相变过程}；
\item ③ 金属氧化物\textbf{活性位的配位结构}（四配位还是六配位、端基还是桥键）；
\item ④ 催化氧化反应中金属氧化物催化剂\textbf{本身的变化}。
\end{itemize}

\textbf{输入}是激发激光与（可以是原位的）样品，\textbf{输出}是拉曼位移—强度曲线；
真正的结论形态是「某物相／某配位物种存在，其相对量随制备条件如此变化」。它\textbf{不}
直接给出比表面积、不给出绝对含量，而且下文会反复出现一个硬边界：\textbf{体相金属
氧化物的拉曼结果主要反映体相结构，不是表面信息}。这一条限制了本节全部结论的外推范围。
\end{probout}

\subsubsection{钼酸铁与钼酸铋：晶相分布与活性相}

\textbf{钼酸铁（iron molybdate）}用于甲醇氧化制甲醛，是最早用拉曼研究的金属氧化物
催化剂。研究结果表明，商品化钼酸铁催化剂中\textbf{晶相结构分布不均匀}，由 \ce{MoO3}、
\ce{Fe2(MoO4)3} 及二者的混合物构成\src{S1 §6.3.1，书内 p.356 / PDF p.375}。反应后
催化剂的表征给出两组谱带：\ce{MoO3} 的主要拉曼峰在 996、\qty{821}{cm^{-1}}、667 与
\qty{285}{cm^{-1}}；\ce{Fe2(MoO4)3} 的相应谱带在 965、\qty{776}{cm^{-1}} 与
\qty{345}{cm^{-1}}。

\begin{obs}
两位候选物相的最高波数谱带落在同一个窗口里：\ce{MoO3} 在 \qty{996}{cm^{-1}}、
\ce{Fe2(MoO4)3} 在 \qty{965}{cm^{-1}}，相差约 \qty{31}{cm^{-1}}，都属端基
\ce{Mo{=}O} 伸缩振动；而两组谱带在 \qty{800}{cm^{-1}} 以下的低波数区差别明显
（\ce{MoO3} 有 667 与 \qty{285}{cm^{-1}}，\ce{Fe2(MoO4)3} 有 776 与
\qty{345}{cm^{-1}}）。此外 \ce{MoO3} 谱带的相对强度明显高于
\ce{Fe2(MoO4)3}\src{S1 图 6-6，书内 p.357 / PDF p.376}。
\end{obs}

\begin{infer}
由上述观察可以推出三条判据，它们各自独立、不可互相代替：

（1）\textbf{物相识别不能只靠最高波数一条谱带}。996 与 \qty{965}{cm^{-1}} 相距仅
\qty{31}{cm^{-1}}，落在峰宽量级内；而低波数区的 667／285 与 776／345 相差可达
\qty{380}{cm^{-1}}，是更可靠的鉴别依据。这与本节末尾「只凭位置不凭对照实验」的误判
条目是同一件事。

（2）\textbf{谱带强度不能当作活性或含量的度量}。\ce{MoO3} 谱带更强，但研究明确表明
\ce{MoO3} 的\textbf{活性远低于} \ce{Fe2(MoO4)3}。\ce{MoO3} 的主要作用是保持催化剂
中 Mo 的浓度——表面 Mo 富集的催化剂具有更高的活性和选择性
\src{S1 §6.3.1，书内 p.357 / PDF p.376}。因此「谁谱峰高谁活性高」在这个体系里恰好
是反的。

（3）由此得到一条实用的组分设计规则：钼酸铁催化剂需要\textbf{富 Mo 的相组成}来维持
Mo 的供给，而承担选择氧化的活性相是 \ce{Fe2(MoO4)3}。判据的落点是「低波数指纹
集合」而非单条谱峰。
\end{infer}

\textbf{钼酸铋（bismuth molybdate）}在丙烯氧化与氨氧化中有重要地位。研究结果表明，
催化剂组成和制备方法的不同会导致钼酸铋中含有多种不同的相，如
\ce{Bi2Mo3O12}、\ce{Bi2Mo2O9}、\ce{Bi2MoO6} 和其他更高 Bi/Mo 比的物相；其中
\ce{Bi2Mo2O9} 是反应活性相，但也可能存在少量其他的铋钼相
\src{S1 §6.3.1，书内 p.357 / PDF p.376}。

\begin{pitfall}
「\ce{Bi2Mo2O9} 是活性相」是一个\textbf{相组成层面}的结论，不等于「测到
\ce{Bi2Mo2O9} 的谱带就说明催化剂好」。原文同时说明可能存在少量其他铋钼相，而拉曼的
检出限与相对灵敏度决定了少量相未必出现在谱图上。把「未检出」读成「不存在」，是本节
反复出现的误判类型之一。
\end{pitfall}

\subsubsection{V-Mg-O 与 V-P-O：相变过程与活性相识别}

\textbf{V-Mg-O 催化剂}在丙烷氧化脱氢中具有好的活性和选择性。随钒含量和焙烧温度的
变化，V-Mg-O 催化剂会形成三种不同的相；对于哪一种相具有更高的丙烯选择性仍存在许多
争议\src{S1 §6.3.1，书内 p.357 / PDF p.376}。Gao 等用柠檬酸法制备了
\ce{MgO}、\ce{Mg3V2O8}、\ce{MgV2O6} 与 $\alpha$-\ce{Mg2V2O7} 三种纯的 V-Mg-O 相，
用拉曼和其他表征手段研究了样品晶相与焙烧温度的关系及与反应性能的关联。结果有三条：

\begin{itemize}
\item 焙烧温度对 \ce{MgV2O6} 相的粒子尺寸与形貌有很强的影响；
\item $\alpha$-\ce{Mg2V2O7} 具有最高的丙烯选择性，其次是 \ce{Mg3V2O8}，最差的是
  \ce{MgV2O6}；
\item 这一选择性顺序与这些相的\textbf{还原性质一致}。
\end{itemize}

第三条是本节最有方法论价值的一条：\textbf{选择性顺序与另一个独立可测的物理量（还原
难易）排序一致}，这就是拉曼物相归属从「谱峰对应」升级为「结论」的那一步。

\textbf{V-P-O 催化剂}在烃类选择氧化中有很强的应用背景。其中含有多种不同的物相，
\ce{(VO)2P2O7} 被认为是活性相，前驱体一般是 \ce{VOHPO4.0.5H2O}。人们采用原位拉曼
对相变过程进行了研究，发现催化剂前驱体在相变过程中\textbf{不是全部规整的变化过程}：
在相变的最初阶段出现了无序的物相；\ce{(VO)2P2O7} 晶相表面最初存在着无序的物相，
表面的非晶相（无序物相）暴露于反应气氛后会转变为有序的晶相；\ce{(VO)2P2O7} 催化剂
初始活性的不断增长与其缓慢晶化有关\src{S1 §6.3.1，书内 p.357 / PDF p.376}。

\begin{measure}
这里的测量条件要点是\textbf{原位}二字：相变中间态只在反应气氛下稳定，淬冷到室温再测
（非原位）很可能已经转完，看到的只是初态与末态。凡是要论证「中间有无序相」的结论，
必须说明谱图是在什么气氛、什么温度下采集的——本节的相变结论全部依赖原位谱，不是
常温谱的推断。
\end{measure}

\subsubsection{体相金属氧化物及其外推边界}

非原位条件下，拉曼光谱已广泛应用于氧化铝、氧化钨、氧化铬、氧化钒、氧化镍、氧化锡等
体相金属氧化物的研究。近年来体相金属氧化物在工作条件下的原位拉曼研究也得到很大发展，
铋-钼催化剂的还原和再氧化是最早使用原位拉曼研究的体相金属氧化物之一
\src{S1 §6.3.1，书内 p.357 / PDF p.376}。

拉曼结果揭示了金属氧化物在氧化反应条件下的多功能性质：① 通过桥式 \ce{Mo-O-Bi} 中的
氧原子可以发生 $\alpha$ 位脱氢；② 在 Mo 位点上，氧或 \ce{NH} 官能团可插入丙烯基中间体
中；③ 氧分子的解离吸附主要发生在 \ce{Bi-O-Bi} 位上。

\begin{pitfall}
原文紧接着给出一句必须与上述三条一起读的限制：\textbf{这些拉曼结果反映的主要是金属
氧化物催化剂的体相结构，不是其表面的信息}。催化发生在表面，而常规拉曼的探测深度在
微米量级，体相信号在强度上压倒表面信号。因此上面三条只能作为\textbf{体相多功能位存在}
的证据，不能直接当作「表面活性位已确证」。要把它们落到表面，需要表面敏感的互补手段
（见本节的「互补与回查」）。
\end{pitfall}

\subsection{拉曼光谱在负载型催化剂中的应用}

负载型金属氧化物催化剂广泛应用于许多工业催化过程，如烷烃脱氢、烯烃聚合、烯烃置换、
有机物的选择氧化、氨化和还原及有机物的消除等反应中。负载型金属氧化物一般是指在氧化物
载体（如 \ce{Al2O3}、\ce{TiO2}、\ce{ZrO2}、\ce{SiO2}）上形成的\textbf{二维表面金属
氧化物}，有时也形成小的晶相氧化物结构\src{S1 §6.3.2，书内 p.357—358 / PDF p.376—377}。

\begin{principle}
\textbf{为什么拉曼是研究负载型氧化物的理想手段}。高分散的金属氧化物相一般都有很强的
拉曼信号，而常用氧化物载体（\ce{gamma-Al2O3}、\ce{SiO2} 等）的拉曼信号通常都较弱，
两者的散射截面差构成了天然的信噪比优势。晶相氧化物在下列情况下较易形成：① 催化剂
合成中前驱体盐在载体表面分散困难；② 载体和金属氧化物存在相互作用；③ \textbf{负载量
超过单层分散量}。第三条给出了本节的主线——\textbf{负载量就是一把可调的「结构刻度尺」}。

\textbf{成立条件}：载体本身荧光弱、且载体谱带不与目标物种谱带重叠。两条中任一条不满足，
这一优势即失效（见本节末的误判条目）。
\end{principle}

\subsubsection{负载量刻度：从四配位到晶相}

用拉曼光谱研究的负载型金属氧化物主要包括氧化钼、氧化钨、氧化铌、氧化钒、氧化铬、
氧化铝、氧化镍等；最早的负载型氧化物拉曼研究始于 20 世纪 70 年代末，主要集中在 V 族、
VI 族和 VIII 族的过渡金属元素。

Medema 等对 \ce{MoO3/gamma-Al2O3} 和 \ce{MoO3/eta-Al2O3} 的研究表明，表面四种类型的
钼物种取决于负载量：\textbf{低于 5\% 时为四配位钼物种；10\%—15\% 时主要为六配位钼
物种；随负载量提高出现 \ce{Al2(MoO4)3} 结构；最后在负载量为 20\%—30\% 时出现了晶相
\ce{MoO3}}\src{S1 §6.3.2，书内 p.358 / PDF p.377}。水的加入导致四配位钼物种的减少和
聚合钼物种的增加。

Jeziorowski 和 Knozinger 研究了不同 pH 制备的 3\,wt\% 与 8\,wt\% \ce{MoO3/Al2O3} 的
拉曼光谱，结论分两层：对 3\,wt\% 的低负载量样品，\textbf{仅观察到孤立的钼物种，与制备
时的 pH 无关}；对 8\,wt\% 样品，pH 影响显著——pH~$=6$ 浸制的催化剂在 \qty{950}{cm^{-1}}
附近有振动，而 pH~$=11$ 浸制时 Mo 端基伸缩振动相应的谱峰位置不同。这种位移表明了表面
物种\textbf{缩合的本性}，即 \ce{Mo-O-Mo} 桥键不同程度的作用
\src{S1 §6.3.2，书内 p.358 / PDF p.377}。

Zingg 等用 Raman、XPS、ISS 和 XRD 等手段对钼物种随负载量的变化进行了研究：在理论单层
的三分之一以下是\textbf{四配位}的氧化钼，随负载量增加出现的是\textbf{六配位}的氧化钼；
达到理论单层时形成了 \ce{Al2(MoO4)3} 结构；在更高负载量时出现了晶相的氧化钼。焙烧时间
的延长和温度的提高\textbf{有利于形成四配位的 \ce{Al2(MoO4)3} 结构}
\src{S1 §6.3.2，书内 p.359 / PDF p.378}。

\textbf{负载型氧化钨}的结果类似：在理论单层的 65\% 以下形成了四配位的氧化钨，随后是
六配位的氧化钨，到达理论单层后形成了晶相氧化钨；\ce{Al2(WO4)3} 只在某些研究中被探测到。
\textbf{负载型氧化钒}的表征表明有两种类型的钒物种：表面与载体键合的钒物种，以及晶相的
五氧化二钒。Wachs 等对不同负载量的 \ce{V2O5/TiO2} 进行了表征：负载量在理论单层以下的
催化剂在 850—\qty{1030}{cm^{-1}} 给出很宽的谱峰，被归属于单层分散的氧化钒；到达单层后
在 \qty{997}{cm^{-1}} 处出现了尖锐的谱峰，被归属于晶相氧化钒的 \ce{V{=}O} 伸缩振动峰
\src{S1 §6.3.2，书内 p.359 / PDF p.378}。

\begin{dataflow}
把上面的散点串成一条可操作的判读链：

\textbf{（观测）}宽峰（850—\qty{1030}{cm^{-1}}）$\rightarrow$ 尖锐峰
（\qty{997}{cm^{-1}}）\\
\textbf{（中间量）}单层分散量——晶相谱峰首次出现时的负载量\\
\textbf{（结论）}该负载量即表面单层分散容量

谢有畅等曾报道氧化物和盐类在载体表面\textbf{自发分散}的现象：当分散物与载体混合后，
在低于其熔点的适当温度下处理就可以自发分散到载体表面。据此，\textbf{由晶相金属氧化物
拉曼谱峰出现时的负载量可以预测表面单层分散容量}。实验测定的结果为：

\begin{itemize}
\item 第 V—VII 族金属氧化物的单层分散容量一般为 \textbf{4—5 原子/nm$^2$}；
\item 氧化锌催化剂由于形成了二聚结构，分散容量只有正常情况的\textbf{一半}
  （即约 2—2.5 原子/nm$^2$）；
\item 氧化钒由于排列得特别紧密，其单层分散容量可达 \textbf{7—8 原子/nm$^2$}；
\item 一个例外是 \ce{SiO2}：由于 \ce{SiO2} 与表面金属氧化物的相互作用很弱，其单层
  分散容量仅为 \textbf{1—3 原子/nm$^2$}，几乎无法形成单层分散。
\end{itemize}

\src{S1 §6.3.2，书内 p.359—360 / PDF p.378—379}
\end{dataflow}

\begin{measure}
「宽峰 $\rightarrow$ 单层分散，尖峰 $\rightarrow$ 晶相」这条判据的\textbf{测量条件}必须
写清楚，否则不可复现：① 峰宽要在同一光谱狭缝宽度下比较，狭缝宽度直接决定仪器展宽；
② 判定「到达单层」依赖负载量序列的完整取样，只有两个负载量点无法定位转折；③ 谱峰
归属要与独立的晶相检出手段（XRD）对照，因为宽峰也可能来自无定形晶相而非单层分散。
\end{measure}

\subsubsection{水合与脱水：一个可逆的结构开关}

负载金属氧化物的结构很容易受到空气中\textbf{水分子}的影响而发生变化。在暴露空气的
情况下，表面负载的金属氧化物的物种是\textbf{水合的}，水合表面物种的分子结构取决于表面
水层零电点时的 pH，其结构与相应盐的聚合结构类似
\src{S1 §6.3.2，书内 p.360 / PDF p.379}。

在脱水条件下表面物种的结构会发生很大变化。以负载型氧化钼为例，脱水后除原来的聚合物种
外，又形成了\textbf{只有一个端基 \ce{Mo{=}O} 键的高度扭曲的独立结构}
\ce{(Si-O-)3Mo{=}O}，导致 \ce{Mo{=}O} 对称伸缩振动向低波数方向位移了
\textbf{50—60 个波数}，\textbf{再次水合后该峰又可逆恢复到原来的波数位置}。在脱水和水合
过程中，\ce{Mo{=}O} 对称伸缩振动峰在 900—\qty{1000}{cm^{-1}} 区间移动——这是由于水的
吸附改变了表面钼物种的结构，因此改变了 \ce{Mo{=}O} 对称伸缩振动峰的频率位置。为了更深入
地从本质上了解氧化钼催化剂结构与拉曼谱峰的关系，Wachs 等在总结了大量数据的基础上，对
\ce{Mo{=}O} 伸缩振动频率与键长的关系给出了经验公式
\src{S1 §6.3.2，书内 p.360 / PDF p.379}。

对其他类型氧化物（如 \ce{V2O5}、\ce{CrO3}、\ce{MoO3}、\ce{WO3}、\ce{Nb2O5}）也发现
了类似的结果。图~\ref{fig:v2o5-hyd}（据原书图 6-8）给出水合和脱水状态下
\ce{V2O5/SiO2} 的谱图：水合 \ce{V2O5/SiO2} 由 \ce{V-O-V} 桥键相连、形成二维高度扭曲的
正四方形单元聚合体，且通过六个 \ce{Si-OH-V} 氢键稳定于氧化硅表面，其拉曼光谱显示特征的
\ce{V2O5.nH2O} 谱峰——端基 \ce{V{=}O} 键（\qty{1026}{cm^{-1}}）、\ce{V-O-V} 键的反对称
伸缩振动（\qty{674}{cm^{-1}}）与对称伸缩振动（\qty{520}{cm^{-1}}）、一个

\textbf{第 VIII 族}负载型过渡金属（Fe、Co、Ni 等）氧化物与第 V—VII 族元素的完全不同：
结构中没有端基 \ce{M{=}O} 键，因此波数最高的谱峰出现在 500—\qty{800}{cm^{-1}} 处，谱峰
强度也明显减弱；另外，与第 V—VII 族金属氧化物相比，\textbf{第 VIII 族负载型金属氧化物
在水合和脱水过程中拉曼光谱并不发生变化}
\src{S1 §6.3.2，书内 p.360 / PDF p.379}。

\begin{infer}
这条族际差别给了读者一个\textbf{免费的内部对照}。第 V—VII 族有端基 \ce{M{=}O}，脱水／
水合可逆位移 50—60 \unit{cm^{-1}}；第 VIII 族没有端基 \ce{M{=}O}，水合脱水谱图不动。
反过来说：如果一份「负载型氧化镍」的谱图在脱水后出现了显著的谱带位移，最可能是
\textbf{样品里混进了 V—VII 族物种（或载体谱带在变）}，而不是 Ni 物种在变。这一条判据
不需要额外实验，只用「该族应当不动」这一点就能查出归属错误。
\end{infer}

\subsubsection{原位拉曼：反应气氛与载体相互作用}

最近的文献主要报道了在不同反应气氛下，负载型金属氧化物分子结构和氧化态的变化。原位
研究对于了解氧化物的结构与催化活性、选择性的关系是十分重要的。早期的原位拉曼研究关注
还原气氛下负载型氧化物的结构变化：\ce{MoO3/Al2O3} 是商品化的加氢脱硫催化剂，氧化钼
物种在 \ce{H2S} 气氛下会经二维的表面氧化钼物种还原为钼氧硫物种，并最终形成
\ce{MoS2} 的晶相结构。在 \ce{TiO2} 上的 \ce{V2O5} 被用于二甲苯选择氧化为邻苯二甲酸酐
和用于 \ce{NH3/O2} 选择性催化还原 \ce{NO_x} 的催化剂：\ce{V2O5} 的小晶粒被 \ce{H2}
还原为 \ce{V2O3}，在 \ce{O2} 气氛下又重新氧化为 \ce{V2O5}
\src{S1 §6.3.2，书内 p.361 / PDF p.380}。

原位拉曼对金属氧化物的光谱研究主要集中在氧化反应中其结构的变化。在两个可比较的氧化
反应的研究中可以很好地观察到\textbf{不同反应环境}对 \ce{SiO2} 负载的表面钼物种的影响
（据原书图 6-9）：脱水条件下氧化硅负载的样品在 \qty{980}{cm^{-1}} 左右给出孤立的表面
钼物种的 \ce{Mo{=}O} 端基振动，\qty{600}{cm^{-1}} 和 500—\qty{300}{cm^{-1}} 的谱峰为
氧化硅载体的拉曼谱峰；在\textbf{甲烷氧化}反应中，钼物种保持了脱水状态的、含有一个端基
\ce{Mo{=}O} 键的结构；而在\textbf{甲醇氧化}的反应中，表面的钼物种转化为晶相的
\ce{MoO3}（842 与 \qty{768}{cm^{-1}}）——这是由于在反应气氛下形成的。若用与表面物种
作用较强的 \ce{Al2O3} 代替相互作用较弱的 \ce{SiO2}，在甲醇氧化反应中表面钼物种的性质
也会改变。以上研究表明，\textbf{可以使用原位拉曼技术在真实的反应条件下，研究不同的
反应气氛和载体相互作用对表面活性相结构的影响}
\src{S1 §6.3.2，书内 p.360—361 / PDF p.379—380}。

\subsubsection{负载型金属硫化物}

负载型硫化钼、硫化钨催化剂是由相应的\textbf{负载型金属氧化物在 \ce{H2S} 气氛下程序升温}
制得的，在工业上主要用作加氢精制催化剂。在这样的工业条件下，二维表面金属氧化物转变为
二维或三维金属硫化物\src{S1 §6.3.3，书内 p.362 / PDF p.381}。

与负载金属氧化物相比，负载金属硫化物的拉曼光谱研究相对较少，原因是\textbf{黑色的硫化物
对可见光的吸收较强，导致信号较弱}。然而拉曼光谱能较易检测到\textbf{小的金属硫化物微晶}。
非负载的晶相 \ce{MoS2} 的拉曼光谱在 \qty{380}{cm^{-1}} 和 \qty{405}{cm^{-1}} 给出谱峰，
分别对应 \ce{MoS2} 的 $E_{2g}$ 和 $A_{1g}$ 振动模式；而负载型晶相硫化钼的谱峰位置与之
不同。钴助剂的加入导致硫化钼的谱峰发生\textbf{位移、强度减弱}，这是由 \ce{Co-Mo-S} 相
及黑色的 \ce{Co-S} 相的形成造成的。随后对 Co-Mo 催化剂的拉曼研究，也\textbf{未能}得到
\ce{Co-S} 和 \ce{Ni-S} 相的拉曼光谱，因为这些物种的\textbf{拉曼散射非常弱}
\src{S1 §6.3.3，书内 p.362—363 / PDF p.381—382}。

\begin{pitfall}
「未能检出 \ce{Co-S} 与 \ce{Ni-S} 的拉曼谱带」是一个\textbf{阴性结果}，它有两种完全
不同的解释：① 这些物种确实不存在；② 它们存在但拉曼散射太弱（原文明确给出的是第②条
原因）。因此本节的行文规范是：对这个体系作结论时只能说「\ce{Co-Mo-S} 相的形成使硫化钼
谱峰位移、强度下降」，\textbf{不}能反过来说「没有 \ce{Co-S} 相」。同理，黑色样品在可见
区的强吸收会同时压低所有谱带，用「某物种谱带缺失」判断物种不存在在这里最不可靠。
\end{pitfall}

\subsection{拉曼光谱在分子筛与表面吸附研究中的应用}

\begin{probout}
分子筛部分要回答的是：\textbf{骨架振动谱带的位置由什么结构量决定，能不能反过来从谱带
位置读出结构？}沸石型分子筛和分子筛型无机微孔材料在催化、吸附和离子交换等领域有广泛
应用；在催化领域中被用于裂解、异构化、烷基化、聚合、脱氢、羰基化、芳构化等很多重要的
工业催化过程。Angel 于 1973 年首次将拉曼光谱用于分子筛骨架研究，迄今天然和合成分子筛
的拉曼研究已有很大发展\src{S1 §6.3.4，书内 p.363 / PDF p.382}。

表面吸附研究部分要回答的是：\textbf{探针分子吸附到表面后，谱带怎么变、变了说明什么？}
输出形态是「吸附方式 + 酸性位类型」这一对结论。两部分合在一节，是因为它们共用同一套
判据——\textbf{谱带位置与相对强度的变化，必须通过与一个参照态（液态探针、纯硅骨架、
空载体）对比才能解释}。
\end{probout}

\subsubsection{分子筛的骨架振动：环数、键角与 Si/Al 值}

分子筛拉曼光谱的最强峰一般出现在 300—\qty{600}{cm^{-1}}，该峰被归属为\textbf{面内
垂直于 \ce{T-O-T} 键（T 指 Si 或 Al）的运动}。对分子筛的研究总结出了
$\nu_{\mathrm{s}}$(T—O—T) 的频率与分子筛结构单元（环大小、T—O—T 键角、Si/Al 值）
之间的对应关系\src{S1 §6.3.4，书内 p.363—364 / PDF p.382—383}。

\textbf{规律一：较小的环对应较高的 $\nu_{\mathrm{s}}$(T—O—T) 频率。}只含有偶数环
（4MR、6MR、8MR、10MR、12MR）的分子筛，该谱峰出现在 \qty{500}{cm^{-1}} 附近；含有五元环
的分子筛，谱峰出现在 390—\qty{469}{cm^{-1}}，具体位置取决于分子筛的环的种类。举例：
Ferrierite 含有五元环、六元环、八元环和十元环，该峰出现在 \qty{430}{cm^{-1}}；而 MFI
（ZSM-5 的骨架类型）和 MOR 含有四元环、五元环、六元环、八元环、十元环和十二元环，该谱峰
出现在 390 和 \qty{460}{cm^{-1}}（举例已逐字对照原页面图像：原书即举 Ferrierite 与
MFI、MOR 三例，未提 Y 型分子筛）。\src{S1 §6.3.4，书内 p.364 / PDF p.383}。表~\ref{tab:zeolite-ring}
给出一些常规分子筛的 $\nu_{\mathrm{s}}$(T—O—T) 振动频率和相应的环数。

\textbf{规律二：谱峰位置依赖 T—O—T 键角。}较大的键角使 T—O 力常数下降，导致
$\nu_{\mathrm{s}}$(T—O) 谱峰向\textbf{低}频率位移。Dutta 等研究了分子筛结构与
T—O—T 键角的关系。

\textbf{规律三：谱峰位置同时依赖交换阳离子的种类。}在
\ce{TlA}—\ce{KA}—\ce{NaA}—\ce{LiA} 系列分子筛中，$\nu_{\mathrm{s}}$(T—O) 从
\qty{470}{cm^{-1}} 增加到 \qty{497}{cm^{-1}}；从 Tl 到 Li，分子筛有较小的键角，从而使
$\nu_{\mathrm{s}}$(T—O) 谱峰出现在较高的频率\src{S1 §6.3.4，书内 p.364 / PDF p.383}。

\begin{principle}
把规律二与规律三合起来，得到一个自洽的因果链，这是本节最值得带走的判据：

\begin{center}
阳离子半径 $\downarrow$（\ce{Tl+} $\rightarrow$ \ce{Li+}）$\Rightarrow$ 骨架被拉紧
$\Rightarrow$ T—O—T 键角 $\downarrow$ $\Rightarrow$ T—O 力常数 $\uparrow$
$\Rightarrow$ $\nu_{\mathrm{s}}$(T—O) 波数 $\uparrow$（470 $\rightarrow$ \qty{497}{cm^{-1}}）
\end{center}

\textbf{可检验的推论}：如果观察到某分子筛的骨架伸缩谱带蓝移，在排除仪器与阳离子因素后，
应当去查\textbf{键角是否真的变小}（XRD 精修）——两条独立证据一致，归属才成立。
\textbf{注意方向}：键角与力常数反向、与波数反向（大键角 $\rightarrow$ 低波数），这是最容易
记反的一条。
\end{principle}

\textbf{Si/Al 值的影响。}一般分子筛的基本结构单元是 \ce{SiO4} 与 \ce{AlO4} 四面体，
骨架中每个氧原子都为相邻的两个四面体所共有，这些基本结构单元按一定组合和排列方式形成
不同结构的分子筛。对于硅铝分子筛，其环数和 T—O—T 键角受铝原子插入的影响，因此
\textbf{Si/Al 值是影响分子筛拉曼振动频率的一个重要因素}。八面沸石中掺杂少量的铝会导致
\qty{298}{cm^{-1}} 与 \qty{312}{cm^{-1}} 的拉曼谱峰\textbf{宽化}，这是由 \ce{Al^{3+}}
在骨架中的\textbf{随机分布}引起的\src{S1 §6.3.4，书内 p.365 / PDF p.384}。

铝的插入还使有拉曼活性的谱峰发生明显位移、强度明显增强，这一效应对于
\qty{500}{cm^{-1}} 附近的\textbf{反对称伸缩振动模式}最为显著。Dutta 及其合作者在 A 型、
X 型、Y 型分子筛中观察到了这类谱峰位移：在纯硅八面沸石中，对应于 1410 与
\qty{1470}{cm^{-1}} 的 \ce{Si-O-Si} 键角的强而锐的谱峰在 \qty{480}{cm^{-1}}，
随 Si/Al 值的增加而逐渐\textbf{宽化并向高频轻微移动}
\src{S1 §6.3.4，书内 p.365 / PDF p.384}。

在 850—\qty{1210}{cm^{-1}} 区域出现的拉曼谱峰一般被归属于 \ce{Si-O} 键的伸缩振动。
不同位置的 \ce{Si-O} 键的键长不同，因此与相邻 T—O 键的偶合程度不同：较大的 T—O—T
键角（\ce{Si-O} 键键长较短）使相邻的 \ce{SiO4} 和 \ce{AlO4} 的偶合程度较大，因此使
\ce{Si-O} 键的频率增加、\ce{Al-O} 键的频率降低。在 NaA 分子筛中，三个不同频率的
\ce{Si-O} 伸缩振动峰被归属于晶格中不同的氧原子，称为 O$_1$、O$_2$ 和 O$_3$ 的位置；
在 X 型分子筛中，954—\qty{1010}{cm^{-1}} 的四个谱峰归属于四个不同位置的氧。

对于大多数分子筛，\qty{600}{cm^{-1}} 和 \qty{850}{cm^{-1}} 及低频部分的谱峰对鉴定
结构有价值：\qty{703}{cm^{-1}} 和 \qty{738}{cm^{-1}} 的谱峰首先被归属为
\ce{Si-O} 的反对称伸缩振动模式；在 ZSM-5 拉曼图中，在 \qty{800}{cm^{-1}} 附近观察到
归属为 \ce{Si-O} 对称伸缩振动的谱峰；\qty{900}{cm^{-1}} 范围内有一组三个或四个谱峰，
对离子交换比（即 Si/Al 值）敏感，其归属与四面体笼中 Si 原子的运动有关。A 型分子筛在低
波数区的 337 与 \qty{410}{cm^{-1}} 谱峰被归属为\textbf{双环的扭曲和环呼吸运动}
\src{S1 §6.3.4，书内 p.366 / PDF p.385}。

\begin{crosscheck}
分子筛的骨架归属有一条\textbf{现成的内部标准样}：\textbf{同结构的纯硅端元}。纯硅八面
沸石（Si/Al $\to \infty$）给出强而锐的 \qty{480}{cm^{-1}} 谱峰；随着 Al 进入骨架，同一
谱峰宽化并轻微蓝移，\qty{298}{cm^{-1}} 与 \qty{312}{cm^{-1}} 的谱峰也宽化。把「纯硅
端元」与「含铝样品」并排比较，就可以把\textbf{铝插入引起的效应}从\textbf{制备条件引起
的效应}里分离出来。

回查规则：任何「Si/Al 值导致谱带位移」的论断，都应报告三个量——纯硅端元的峰位、
样品的峰位、以及独立的 Si/Al 化学分析值。缺任一项，位移就无法归因。
\end{crosscheck}

\subsubsection{杂原子分子筛与合成过程的原位跟踪}

\textbf{（1）杂原子分子筛。}过渡金属杂原子分子筛的研究中，一般用 \qty{960}{cm^{-1}}
谱峰的增强来判断骨架中杂原子的存在。迄今该峰的归属尚存争议，候选解释包括
\ce{Ti-O-Si} 振动、硅羟基、与钛相关的缺陷位或 \ce{Ti-O-Si} 桥键等。锐钛矿（\ce{TiO2}
的一种晶型）的谱峰在 144、390 与 \qty{627}{cm^{-1}}，可用来判断样品中是否含有晶相
\ce{TiO2}——这一点对 \qty{960}{cm^{-1}} 峰的归属至关重要，因为晶相 \ce{TiO2} 的存在
会混淆判断。也有对其他杂原子分子筛的研究
\src{S1 §6.3.4，书内 p.366 / PDF p.385}。

Prakash 和 Kevan 用拉曼光谱研究了 Nb 取代的分子筛，在 \qty{930}{cm^{-1}} 和
\qty{970}{cm^{-1}} 给出两个谱峰，这些谱峰在 Si 端元中不出现，可归属为
\ce{Nb-O-Si} 的伸缩振动，被认为是在骨架中存在\textbf{四面体 Nb 原子}的证据。Kosslick
等也研究了 MFI 分子筛骨架的 Ge 原子同晶取代效应，在 \qty{400}{cm^{-1}} 观察到对
\ce{Si-O-Si} 或 \ce{Si-O-Ge} 变形振动最灵敏的谱峰；\qty{685}{cm^{-1}} 的拉曼谱峰随着
Ge 含量的增加逐渐增强，该谱峰被归属为对称伸缩振动，对应于分子筛骨架中\textbf{四面体
配位}的 Ge。随着 Ge 含量的增加，T—O—T 变形振动谱峰向\textbf{高}波数移动，而
\ce{Si-O-Si} 的对称伸缩振动谱峰向\textbf{低}波数移动，说明 Ge 的掺杂引起了
\textbf{T—O—T 键角的减小}
\src{S1 §6.3.4，书内 p.366 / PDF p.385}。

\begin{obs}
Ge 掺杂体系的观察可以归成三条互相独立、方向不同的位移：
\ce{Si-O-Si} 对称伸缩（$\approx$ \qty{800}{cm^{-1}} 附近）\textbf{红移}；
T—O—T 变形振动（$\approx$ \qty{400}{cm^{-1}}）\textbf{蓝移}；
\qty{685}{cm^{-1}} 归属四面体 Ge 的对称伸缩谱带\textbf{增强}。
\end{obs}

\begin{infer}
三条位移必须与规律二联立才能自洽：Ge 进入骨架后 T—O—T 键角减小，按「大键角 $\rightarrow$
低波数」，键角减小应使 T—O—T 相关模式蓝移——与观察到的一致；同时键角减小意味着
\ce{Si-O} 键被拉长、力常数下降，故 \ce{Si-O-Si} 对称伸缩红移——也与观察到的一致。
\textbf{两条符号相反的位移由同一个结构变化（键角减小）解释}，这正是归属可信的证据结构：
不是「一条谱带对应一个物种」，而是「一组符号已知的位移对应一个结构量」。

\textbf{边界}：这条推理只给出「键角减小」这一相对结论，\textbf{不}给出键角的绝对数值；
后者必须由 XRD 精修等独立方法提供。
\end{infer}

\textbf{（2）分子筛的合成。}由于水溶液本身的拉曼信号较弱，因此可以在\textbf{液相和固相
同时跟踪}分子筛的合成过程，这是拉曼在分子筛领域不可替代的一点。若分子筛的合成过程是从
硅溶胶开始的，在 450—\qty{460}{cm^{-1}} 出现宽峰，被归属于\textbf{玻璃态硅}的拉曼光谱
\src{S1 §6.3.4，书内 p.366—368 / PDF p.385—387}。

对 A 型、X 型分子筛的合成研究表明，在\textbf{液相}中首先探测到 \qty{620}{cm^{-1}} 的
谱峰，被归属于 \ce{Al(OH)4^-} 物种；随时间延长该峰消失，说明 Al 很快进入了固相。同时
在液相中出现了 \qty{780}{cm^{-1}} 强峰以及 441 和 \qty{919}{cm^{-1}} 的弱峰，它们是
单一 \ce{[SiO2(OH)2]^{2-}} 物种的特征峰。在 \qty{601}{cm^{-1}} 和
\qty{1025}{cm^{-1}} 出现的弱峰是\textbf{二聚硅物种}的特征峰。这些数据表明，在最初的
合成阶段\textbf{铝离子进入固相中而硅离子释放到溶液中}。

在晶化过程的最初阶段，固相溶胶的拉曼光谱在 460、\qty{800}{cm^{-1}}、
\qty{1000}{cm^{-1}} 出现了谱峰，表明固相仍处于\textbf{无定形状态}。对 Y 型分子筛的
合成：首先在低波数区出现了 440 与 \qty{361}{cm^{-1}} 的谱峰，说明四元环形成；随后在
\qty{500}{cm^{-1}} 出现了谱峰，说明带有四元环的\textbf{方钠石结构}形成了。对 A 型
分子筛，\qty{500}{cm^{-1}} 谱峰的出现说明在最初阶段形成了四元环。

在 Mordenite 和 ZSM-5 的合成过程中，最初出现的仍然是玻璃态的硅铝骨架。ZSM-5 的合成
过程中，新峰只有在晶化以后才会出现：最初出现的是 \qty{495}{cm^{-1}}，说明形成了四元环
的结构；随后出现了 \qty{402}{cm^{-1}} 附近的宽峰，证明有\textbf{五元环}的结构出现
\src{S1 §6.3.4，书内 p.367 / PDF p.386}。

Dutta 等详细研究了 A 型分子筛的合成，包括溶胶的形成及晶化各阶段。以
$6\ce{Na2O}:\ce{Al2O3}:15\ce{SiO2}:56\ce{H2O}$（原文 OCR 作
「s石N助0:l川20:15102:56H20」）作为初始组成\src{S1 图 6-13，书内 p.367 / PDF p.386}，
在 \qty{700}{cm^{-1}}（原文此处被页边裁断，见
\tocheck{未对照原页面图像：Dutta 的 A 型合成谱带列表中，700 与 \qty{733}{cm^{-1}}
两个值的上下文被版心裁断，无法确认其完整归属句}）、\qty{733}{cm^{-1}}、
\qty{745}{cm^{-1}}、\qty{970}{cm^{-1}} 等位置观察到强度变化。图中
\qty{504}{cm^{-1}} 的拉曼谱峰相应于 XRD 表征中随机无序构成的\textbf{四元环无定形溶胶}；
在溶胶向晶相转变过程中，450、\qty{847}{cm^{-1}} 和 \qty{960}{cm^{-1}} 的拉曼谱峰强度
下降，\qty{504}{cm^{-1}} 谱峰向低波数方向位移，表明胶体和 \ce{Al(OH)4^-} 相互作用形成
四元环结构，并在成核过程中形成了 A 型分子筛的晶核
\src{S1 §6.3.4，书内 p.368 / PDF p.387}。

\begin{dataflow}
\textbf{分子筛合成的「液—固双通道」判读链}：拉曼同时看液相与固相，因此可以把一个合成
过程拆成两条互相咬合的曲线——

\textbf{液相通道}：\qty{620}{cm^{-1}} 出现 $\rightarrow$ 消失（Al 进固相）；
\qty{780}{cm^{-1}} 出现并增强（硅被释放到溶液，以单体硅酸根存在）；
\qty{601}{cm^{-1}}／\qty{1025}{cm^{-1}} 弱峰（二聚硅物种）。

\textbf{固相通道}：450—\qty{460}{cm^{-1}} 宽峰（玻璃态硅，无定形）
$\rightarrow$ \qty{500}{cm^{-1}} 出现（四元环）$\rightarrow$ 骨架谱带强度上升（晶化）。

\textbf{结论}：最初阶段\textbf{铝进固相、硅出液相}；晶核由四元环构成；成核是「四元环
$\rightarrow$ 方钠石笼」的过程。两条通道的方向相反（一个减少、一个增加），互为对照，
这是拉曼能作此结论的关键。
\end{dataflow}

Dutta 等又研究了 Y 型分子筛晶化过程中液相和固相的变化，并考察了\textbf{老化时间}的
影响。在最初晶化时，首先在 \qty{620}{cm^{-1}} 观察到强的拉曼峰；老化 6\,h 后，在
\qty{750}{cm^{-1}} 出现强的拉曼峰，并在 441 与 \qty{919}{cm^{-1}} 出现弱的拉曼峰，这些
是单一 \ce{[SiO2(OH)2]^{2-}} 物种的特征谱峰；归属为二聚硅物种的弱谱峰在
\qty{601}{cm^{-1}} 和 \qty{1025}{cm^{-1}} 出现。在 Y 型分子筛合成的固相拉曼光谱中，
\qty{440}{cm^{-1}} 谱峰是铝硅酸盐\textbf{六元环}的特征谱峰；根据环尺寸和
$\nu_{\mathrm{s}}$(T—O—T) 频率的对应关系，认为在分子筛成核过程中在铝硅相中存在着六元环
结构。Y 型分子筛以这些环作为构建单元的成核过程，是一个经过四元环形成方钠石笼的过程
\src{S1 图 6-14，书内 p.368 / PDF p.387}。

Dutta 等还研究了 ZSM-5 的合成过程，在 300—\qty{650}{cm^{-1}} 和
650—\qty{1550}{cm^{-1}} 两个区域内跟踪固相晶化过程。在低波数区，可观察到归属为硅铝骨架
的一个宽谱峰（$\approx$ \qty{460}{cm^{-1}}），这是典型的无定形或玻璃硅的特征峰，被归属
为五元环或六元环的 $\nu_{\mathrm{s}}$(Si—O—Si)。在加热 4 天后，XRD 可检测到晶相的生成，
拉曼光谱也有很明显的变化：硅铝分子筛骨架的 373、\qty{473}{cm^{-1}} 和
820—\qty{832}{cm^{-1}} 谱峰强度明显增加。在 A 型和 Y 型分子筛合成中标志性的
\qty{500}{cm^{-1}} 四元环谱峰，在 ZSM-5 的合成过程中\textbf{并未出现}，说明
\textbf{五元环是最初的原始结构，而不是四元环}
\src{S1 §6.3.4，书内 p.368—369 / PDF p.387—388}。

\begin{pitfall}
ZSM-5 的这条结论是\textbf{阴性与阳性证据的组合}，报告时必须把两半都写出来，缺一半就
不成立：

\textbf{阳性}：晶化后 373／473／820—\qty{832}{cm^{-1}} 谱峰强度明显上升；
\textbf{阴性}：A 型与 Y 型合成中标志四元环的 \qty{500}{cm^{-1}} 谱峰在这里不出现。

只看「强度上升」会得出「生成了某种骨架」，只有把「四元环标志峰缺席」一并纳入，才能
得出「最初是五元环而非四元环」。这与本节其他阴性结果（\ce{Co-S} 未检出）一样，是
\textbf{需要主动声明灵敏度边界}的位置。
\end{pitfall}

\begin{pitfall}
\textbf{分子筛拉曼的最大问题始终是荧光。}在分子筛科学发展的过程中，拉曼光谱远不如红外
光谱应用得那样广泛：一方面拉曼散射强度的本征灵敏度较低，另一方面分子筛样品的荧光干扰
很强，所以很难得到信噪比很好的拉曼光谱。荧光主要来自过渡金属离子（如 \ce{Fe^{3+}}、
\ce{Cr^{3+}} 和 \ce{Mn^{2+}}）、有机物杂质和含铝分子筛的酸性位。可以采取的抑制手段：
用纯度较高的原料克服过渡金属离子引起的荧光；通过氧化过程或强光照射降低有机物杂质引起
的荧光；通过焙烧减弱酸性位引起的荧光干扰。但是\textbf{荧光干扰仍然是分子筛拉曼表征的
最主要问题}\src{S1 §6.3.4，书内 p.369 / PDF p.388}。
\end{pitfall}

\subsubsection{表面吸附研究：探针分子与酸性位}

1970 年和 1971 年，Hendra 和 Loader 等报道了 \ce{C2H4}、\ce{Br2} 和 \ce{CS2} 等物种
吸附的拉曼光谱，\textbf{首次}研究了化学吸附和物理吸附对化合物特征振动模式的影响。随后
一些研究小组以\textbf{吡啶}为探针对氧化物表面的酸性进行了研究，这是对吡啶在氧化物表面
的化学吸附、以及识别 Br\o nsted 酸和 Lewis 酸的红外研究的\textbf{补充}
\src{S1 §6.3.5，书内 p.369 / PDF p.388}。

\begin{measure}
吡啶探针的可监控谱峰有两组：吡啶在 \qty{1000}{cm^{-1}} 左右的\textbf{环振动}，以及在
\qty{3000}{cm^{-1}} 附近的 \ce{C-H} 伸缩振动。吸附态吡啶的光谱（包括它们的谱峰宽度、
位置和相对强度）是通过与\textbf{液态吡啶}的光谱相比较而归属的。与表面的相互作用程度，
通过 Lewis 酸配位物种的振动位置来显示：如液态吡啶的 \ce{C-N} 伸缩振动在
\qty{991}{cm^{-1}}，配位后在 \qty{1019}{cm^{-1}} 附近\src{S1 §6.3.5，书内 p.370 /
PDF p.389}。\textbf{关键测量约定}：液态参考谱必须在同一仪器、同一狭缝宽度下采集，否则
「相对于液态位移了多少」这个量不可比。
\end{measure}

早期拉曼光谱研究 \ce{Al2O3} 表面的吸附包括硝基苯、\ce{C2H5CN} 和 \ce{C6H5CN} 等，
其中有一例是\textbf{一个表面物种随反应时间变化}的拉曼光谱研究。Angel 等用拉曼光谱研究了
\ce{CO2}、丙烯、乙腈和丙腈在分子筛上的吸附：这些分子吸附后的拉曼谱峰与其液态的拉曼谱峰
基本相似，仅是丙烯的 \ce{C-C} 伸缩振动频率和乙腈的 \ce{C#N} 伸缩振动有很大的差别，
这正是\textbf{吸附效应}的显示\src{S1 §6.3.5，书内 p.370 / PDF p.389}。

Scheffer 和 Cheng 对 \ce{gamma-Al2O3}、不同负载量的 Mo 催化剂以及
\ce{CoO-MoO3/gamma-Al2O3} 的吡啶吸附进行了研究。他们发现表面 Lewis 酸随负载量的不同
发生变化，并与表面物种的结构进行了关联。表~\ref{tab:pyridine} 列出吡啶吸附在
\ce{MoO_x/Al2O3} 与 \ce{CoO-MoO3/gamma-Al2O3} 上的拉曼谱峰位置。结论有四条：

\begin{itemize}
\item Lewis 酸位上配位的吡啶在 \qty{1017}{cm^{-1}} 给出一特征谱峰；
\item Mo 负载量从 5\% 到 10\% 时，Br\o nsted 酸位上配位的吡啶在
      \qty{1047}{cm^{-1}} 给出一特征谱峰；
\item 在加入 CoO 后，\textbf{Br\o nsted 酸位消失}；
\item 随着 Mo 含量增加到晶相 \ce{MoO3} 出现，\textbf{没有观察到 Lewis 酸性的降低}。
\end{itemize}

\begin{crosscheck}
吡啶吸附这一组数据是拉曼与红外\textbf{分工}的教科书案例，两者的边界恰好互补：

\textbf{拉曼的独有窗口}：一般载体的红外光谱在 \qty{1200}{cm^{-1}} 以下范围内有很强的
吸收，而拉曼光谱受载体的影响较小，因此可以在此范围内得到表面物种的拉曼光谱。这正是
吡啶环振动（$\approx$ \qty{1000}{cm^{-1}}）与 \ce{C-N} 伸缩
（991／1019 \unit{cm^{-1}}）落在拉曼可用区的原因。

\textbf{局限}：吸附分子的拉曼研究远远不如红外开展得那么普遍，原因是拉曼光谱的原位研究
存在一定困难，其中\textbf{荧光干扰和灵敏度较低是最大的问题}。

回查规则：识别 Br\o nsted 酸与 Lewis 酸的\textbf{经典判据在红外}，拉曼在这里承担的是
补充与交叉确认。凡只有拉曼一条证据就说「Br\o nsted 酸位消失」的，应当用红外吡啶吸附
回查——但反过来，在 \qty{1200}{cm^{-1}} 以下红外几乎无窗口时，拉曼是唯一选择。
\end{crosscheck}

\subsection{原位拉曼反应研究}

\begin{probout}
原位反应研究要回答的是：\textbf{在工作条件下，催化剂的活性相到底变成什么？}拉曼用于
原位反应研究有三条独特优势\src{S1 §6.3.6，书内 p.371 / PDF p.390}：

\begin{itemize}
\item \textbf{（1）气相光谱的干扰非常弱}，因而能在高温高压工作条件下获得催化剂的原位
  拉曼光谱；
\item \textbf{（2）固体吸附剂或载体的拉曼散射一般都很低}，特别是最典型的载体氧化物如
   \ce{SiO2} 和 \ce{Al2O3} 等，能得到低频区表面吸附物种的拉曼光谱；
\item \textbf{（3）避开黑体辐射}。在红外光谱中，高温时遇到的问题是来自样品和样品池的
   \textbf{黑体辐射}；当用短波长或紫外激光作为激发线时，在拉曼光谱上可以避免黑体辐射
  产生的干扰。
\end{itemize}

\textbf{输出}不是一张静态谱图，而是「活性相的身份 + 它随气氛／温度的变化路径」。
\end{probout}

\subsubsection{活性相识别：从钼酸铋到 V-P-O}

烯烃部分氧化和氨氧化的催化剂钼酸铋有许多不同的相组成，其中 \ce{Bi2Mo2O9} 是反应活性相。
Glaeser 等第一次报道了烯烃选择氧化的原位激光拉曼研究，提供了催化剂\textbf{活性位结构
识别}的信息。他们的做法值得注意：首先用 1-丁烯、丙烯、甲醇和氨等\textbf{探针分子还原}
钼酸铋催化剂，然后用标记的 \ce{^{18}O2} 对催化剂进行\textbf{再氧化}，来确定催化剂对
丙烯氧化和氨氧化反应的活性中心；结果发现与多功能位上 \ce{Bi-O-Bi} 相关的孤对电子与
\ce{O2} 的化学吸附、还原和解离是有关的
\src{S1 §6.3.6，书内 p.371 / PDF p.390}。

Laskier 等用原位拉曼光谱研究了正丁烷氧化催化剂 VPO，发现有两种活性中心位，分别对应于
\textbf{完全燃烧}和\textbf{选择氧化}。Volta 等研究了丁烷氧化过程的催化剂，发现
\ce{(VO)2P2O7} 相在反应条件下是稳定的，而 $\beta$-\ce{VOPO4} 会转变为
$\alpha$-\ce{VOPO4}\src{S1 §6.3.6，书内 p.371—372 / PDF p.390—391}。

\begin{principle}
\textbf{同位素标记法为什么能把归属从「相关」提升到「因果」。}把 \ce{^{16}O2} 换成
\ce{^{18}O2} 后，含氧物种的振动频率按约化质量变化移动，$\tilde\nu \propto 1/\sqrt{\mu}$。
对端基 \ce{M{=}O}，\ce{^{16}O} $\rightarrow$ \ce{^{18}O} 使约化质量由 16 增至 18
（以 M 很重、近似 $\mu \approx m_{\mathrm{O}}$ 计），频率比约
$\sqrt{16/18} \approx 0.943$；对 \qty{996}{cm^{-1}} 的 \ce{Mo{=}O}，预期位移约
\qty{-57}{cm^{-1}}，即移到 \qty{939}{cm^{-1}} 附近。同位素位移是\textbf{方向与大小都可
预测}的，因此「标记氧出现在哪条谱带上」直接指认了氧的来源——这是纯位置比较做不到的。

\textbf{成立条件}：M 的质量远大于 O（对 Mo、Bi、V 成立）；只考虑双原子近似，
桥氧因与两个金属偶合，位移会显著小于上述估计值。
\end{principle}

\subsubsection{表面氧物种的生成—消耗}

\ce{CH4} 和 \ce{O2} 或 \ce{N2O} 在碱性催化剂上氧化偶联可得到 \ce{C2} 产品。Lunsford 等
对 Ba/MgO 催化剂的 XPS 研究表明，催化剂的本征活性与之有很大的关系；用原位拉曼光谱在
反应条件下也可检测到\textbf{过氧离子}的存在，其谱峰为 520—\qty{550}{cm^{-1}}
\src{S1 §6.3.6，书内 p.372 / PDF p.391}。

据原书图 6-16，\ce{Ba/MgO} 催化剂在 \qty{800}{\degC} 氧气气氛下处理后，冷却到不同温度
采集拉曼光谱：催化剂在 \qty{100}{\degC} 的拉曼光谱给出一强谱峰，这一谱峰在纯 \ce{BaO2}
的光谱中也可以观察到，被归属为 \ce{O2^{2-}} 的 \ce{O-O} 伸缩振动；829 与
\qty{821}{cm^{-1}} 两个弱的谱峰，可归属为处于\textbf{不同环境}的 \ce{O2^{2-}} 物种。
随着温度的升高，\qty{842}{cm^{-1}} 处的谱峰移动且变宽、强度下降；他们认为谱峰的宽化和
强度下降是由高温条件下\textbf{无序度的增加}和 \ce{BaO2} 的\textbf{降解}所致，这种变化
和他们的 \ce{C2} 催化性能是一致的。这种 \ce{O2^{2-}} 物种在 \ce{La2O3} 和 Na 修饰的
\ce{La2O3} 催化剂上也能观察到。表征加入 30\% \ce{BaO} 或 \ce{BaX2} 的 \ce{Nd2O3}
催化剂，发现其表面有双氧物种 \ce{O2^{2-}} 和 \ce{O2^-} 的存在；双氧物种的产生是
\ce{Ba^{2+}} 取代 \ce{Nd^{3+}} 的结果，\ce{Nd2O3} 的甲烷氧化偶联催化活性——特别是
\ce{C2} 产品的选择性——由于这种双氧物种的存在得到很大的提高
\src{S1 §6.3.6，书内 p.372 / PDF p.391}。

\begin{dataflow}
把 Ba/MgO 这一例整理成「表面氧物种的生成—消耗」跟踪链，这是原位拉曼在本节最典型的
用法：

\textbf{（预处理／生成）} \qty{800}{\degC}、\ce{O2} 气氛 $\rightarrow$ 生成
\ce{O2^{2-}}（过氧物种）\\
\textbf{（降温观测）} 冷却到 \qty{100}{\degC} $\rightarrow$ 强谱峰 + 829／821
\unit{cm^{-1}} 双弱峰 $\rightarrow$ 存在\textbf{两种不同环境}的 \ce{O2^{2-}}\\
\textbf{（升温／消耗）} 温度升高 $\rightarrow$ \qty{842}{cm^{-1}} 谱峰位移、宽化、强度
下降 $\rightarrow$ 无序度增加 + \ce{BaO2} 降解\\
\textbf{（外部一致性）} 该变化与 \ce{C2} 催化性能的变化\textbf{方向一致}

\textbf{结论}：520—\qty{550}{cm^{-1}} 与 820—\qty{842}{cm^{-1}} 一带的谱带可作为过氧
物种的标志；加入 Ba 提高选择性的原因，可落到「\ce{Ba^{2+}} 取代 \ce{Nd^{3+}} 产生双氧
物种」这一结构事件上。
\end{dataflow}

\begin{pitfall}
把「表面氧物种」的归属做扎实，必须同时排掉下面几类\textbf{伪证据}，它们是本节
（以及全部氧化物拉曼）最常出错的五个位置：

\begin{itemize}
\item \textbf{激光加热导致谱带位移}。原位池里激光功率高、样品导热差，局部温升可达
  数十度；上文的 \qty{842}{cm^{-1}} 谱峰随温度位移、宽化，其驱动量既有样品真实变化，
  \textbf{也可能包含激光自身加热}。判据：在同一设定温度下改变激光功率，若谱峰位置随之
  移动，则位移中含有加热贡献，必须扣除或改用低功率长积分。
\item \textbf{荧光背底被当成宽峰}。强荧光给出缓慢起伏的背底，容易被读成一个「很宽的
  谱峰」并顺势归为无定形物种。判据：改变激发波长，拉曼峰位移不动而荧光背底整体移动；
  两者行为不同。
\item \textbf{水与羟基的干扰}。水的拉曼散射虽弱但非为零，表面羟基与吸附水的谱带会在
  900—\qty{1000}{cm^{-1}} 一带混入；而这一段正是 \ce{Mo{=}O} 与 \ce{V{=}O} 端基振动的
  窗口，且本节已确认 \textbf{脱水／水合可使该峰可逆移动 50—60 \unit{cm^{-1}}}。
  判据：\textbf{凡把 900—\qty{1000}{cm^{-1}} 的谱带用于定量或物相归属，必须先报告
  样品的脱水状态}。
\item \textbf{把载体谱带当成活性物种}。\ce{SiO2} 的 \qty{920}{cm^{-1}} 与
  \qty{490}{cm^{-1}} 弱峰、\ce{MoO3/SiO2} 体系中 \qty{600}{cm^{-1}} 与
  500—\qty{300}{cm^{-1}} 的谱峰，都已明确是\textbf{氧化硅载体}的谱峰。判据：\textbf{空
  载体必须作为独立参照样测一遍}，否则无法区分「载体」与「负载物种」。
\item \textbf{只凭位置、不凭对照实验归属}。\qty{960}{cm^{-1}} 峰在杂原子分子筛中的归属
  至今存在多种候选解释（\ce{Ti-O-Si} 振动、硅羟基、缺陷位、\ce{Ti-O-Si} 桥键），单凭
  位置无法区分。同样，\ce{MoO3}（996）与 \ce{Fe2(MoO4)3}（965）相差仅
  \qty{31}{cm^{-1}}。可行的对照包括：纯物相标样、同位素标记（\ce{^{18}O2}）、负载量
  序列、以及红外／XRD 等独立手段。
\end{itemize}
\end{pitfall}

\begin{crosscheck}
本节的两处限制需要在结论层面重申一次，它们限定了全部拉曼结论的\textbf{适用范围}：

\textbf{（1）体相 vs 表面}。拉曼能给出金属氧化物的体相结构信息，且在反应气氛下能跟踪
活性相转变；但如前所述，这些结果反映的主要是体相结构，不是表面信息。表面结论需要与
表面敏感手段（XPS、化学吸附、探针分子吸附）联合。

\textbf{（2）灵敏度与荧光}。拉曼在负载型金属氧化物研究中不但得到了表面物种的结构信息，
而且能将结构与反应活性和选择性进行很好的关联，这在催化研究中是非常重要的；但是，由于
载体一般有很强的荧光干扰，使一些氧化物特别是低负载量氧化物的\textbf{常规拉曼光谱研究
遇到了很大的困难}\src{S1 §6.3.2，书内 p.362 / PDF p.381}。黑色硫化物体系同理（可见光强
吸收 $\rightarrow$ 信号弱）。

\textbf{回查清单}：任何一条「某物种存在／某活性相生成」的原位拉曼结论，交付前应能回答：
① 空载体参照谱是什么样？② 样品脱水状态如何？③ 激光功率是否影响了峰位？④ 是否有一条
独立方法（XRD／XPS／同位素标记／反应动力学）与之同向？四条都能回答，结论方可保留。
\end{crosscheck}
