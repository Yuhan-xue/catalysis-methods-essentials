# 全书逐页验收台账

制品 `build/main.pdf`（339 页 / 145 书签），源码提交 `427ec18`。生成日期 2026-10-13。

**方法。** `tools/page_audit.py` 对全部 339 页逐页做结构审计——版心越界（已分离标点悬挂与亚容差偏移）、孤悬标题、重复行与真叠印鉴别、缺字、页眉/页码缺失、页尾留白、页内无内容空白带、墨迹出界——结果落 `build/page_audit.csv`；再以接触印相表（`tools/pagesheet.py`）对全书逐页目视复核版面，每批 20 页。另两项独立核对：`tools/check_folio.py` 逐页比对页脚数字与 PDF 页序、并按奇偶页清点页眉；`tools/check_toc.py` 把目录每一条的印刷页码回到正文页里搜标题文字复核。

**判定口径。**
- `依据` 列给实测值。`rowl`/`rowr` 是**真正的**版心越界；行首/行尾标点悬挂（`hang_l`/`hang_r`）是 xeCJK 的既成排版行为（全书 0 处 overfull hbox 可互证），≤2pt 的偏移（`edge_l`/`edge_r`）记为居中量级；`gap_ct` 是「正文行 ∪ 版心内矢量 ∪ 位图」并集后的最大竖向空白带，`dup_over` 是文字框双向重叠的真叠印。
- `PASS` 无缺陷类标记；`INFO` 信息级（亚容差偏移、短页、重复行等，已排除为既成事实或误报）；`WARN` 已知但本轮不改的版面瑕疵；`FLAG` 需要修复的真实缺陷。
- 行首/行尾**标点悬挂**（`hang_l`/`hang_r`）只在依据列示出，**不抬升判定等级**——它是 xeCJK 的既成排版行为，且出现在 339 页中的 318 页；若把它算作标记，判定列就失去区分度。

**覆盖边界（不夸大）。** 结构审计 339/339 页；接触印相表目视复核 339 页 = 第 1—339 页整批扫读（17 批 × 20 页，40dpi 接触印相表，逐格看版面；本版为 339 页重建，自第 163 页起相对上一版整体位移一页、同一材料未删内容，重排涉及的关键页已重新读图）——全书 339 页至此已逐页读过版面，不再有「未列入重点页」的盲区。40dpi 只够判断版面，读不出错字与乱码，本台账不主张内容级校对，也不替代此前的表格/公式核对台账。**本台账随制品重建而重算**：内容级修订会让页内重新排版（本版 339 页，相对上一版 340 页，自第 163 页起正文行分配整体位移一页，前 162 页的正文文字层与上一版逐页相同；相对上一版 339 页制品，本版仅第 246—264 页页内重排——ch10-b 补入核对说明与两条公式说明所致，页数与页序不变、无位移特征），页级判定的构成随重排更新；`依据` 列始终是当前制品的实测值，页级备注已按当前页的实测重新复核。

**另两项逐页核对（不依赖读图）。** 页脚数字与页序：339 页中 338 页页码正确，唯一无页码的是第 1 页扉页；页眉共 18 种——偶页统一为书名（169 页），奇页为章名/附录标题共 17 种（扉页无页眉），每种只出现在一种奇偶性上，无奇偶混用。目录：61 条目录项的印刷页码全部落在其标题文字实际所在的页上（61/61，0 处不符、0 处找不到）。

**另三项文本层核对（不看图，纯文字层）。**
- 重复页：`tools/check_duppages.py` 逐页取正文文字——339 页正文全部非空（0 页空正文），完全相同的页 0 组、近似重复页（Jaccard > 0.60）0 对；即全书无重复页，也无同一分片被 `\input` 两次。
- 书签落点：`tools/check_bookmarks.py` 把 145 个书签逐条回到目标页搜其标题文字——145/145 命中（0 处不符、0 处找不到）。其中 3 条章级书签的列表编号不与页面印刷的「第 N 章」相邻（如书签「2 透射电子显微镜」对页面的「第2章 透射电子显微镜」），去掉前导编号后再匹配即命中，报告里计为 `fallback=3`。
- 编号连续性：`tools/check_numbers.py` 只认行首题注。**结论以源码为准**：`chapters/` 中没有任何硬编码的图/表编号、没有 `\tag`、没有对这三个计数器的 `\addtocounter`/`\setcounter`，编号全部由 LaTeX 计数器生成，**构造上连续、不可能跳号**。该探针因此只用于发现「题注行没被看见」的位置：38 个族中 9 族有未在行首看到的编号，输出已相应标为 `UNSEEN`（而非 GAP），并在此说明这不是编号缺陷。40dpi 与文字层都读不出公式数值与错字，本台账不主张这两项。
