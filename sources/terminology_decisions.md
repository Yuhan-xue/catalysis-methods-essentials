# 术语统一决定（阶段 4）

来源：15 个正文分片由不同作者独立写成，术语必然出现分歧。用
`python tools/check_terms.py` 扫描（结果在 `tools/term_audit.txt`），
用 `python tools/fix_terms.py` 施加统一（日志在 `tools/fix_term_log.txt`）。

**判定原则**：工具只报告「同一概念出现多种写法」这一事实，**不判断哪种对**。
由 Lead 结合本专业中文习惯与本书章节标题逐一裁定。有些分组是**误报**，
不能机械替换——下面「刻意不改」一节记录了这些，避免后来者重复劳动或改错。

## 二、刻意不改（误报或正当用法）

### 1. `转换频率` vs `转换数` —— **不是同义词，是两个不同的量**

- **TOF**（turnover frequency，转换频率）：单位时间、单位活性位上的转换次数，量纲 s⁻¹
- **TON**（turnover number，转换数）：催化循环累计的总包反应次数，无量纲

`ch10-a` 第 137 行小节标题就是「转换数与转换频率（TOF）」，140 行定义 TON，
147 行在 TOF 定义里用「单位时间内单位活性位上发生的转换数」——**用法全部正确**。
`ch90-backmatter` 缩写表也分别列出 TOF 与 TON 两条。

**若后来者按工具报告把它们统一，会制造出真正的错误。** 这一条务必保留。

### 2. `透射电子显微镜` vs `透射电镜`

首次出现用全称、其后用简称，是**正确的中文科技写作规范**，不是不一致。
同理适用于扫描电子显微镜／扫描电镜。

### 3. `标定` vs `校准`

两者都是规范用语，且分工略有不同：`标定` 多用于「用标准物确定量值」
（标定曲线、熔点标定），`校准` 多用于「校正仪器标尺」
（谱仪能量标尺校准）。保留现状，但要求**同一语境内部不得混用**：

- 全书主导形式为 **标定**（27 次），`校准` 7 次集中在两处：
  - `ch09-c`「定量与校准」小节：引 ISO 17973／ISO 15472 等标准，
    标准中文题名用「校准」，属**引文用词**，不改；
  - `ch09-a` 与 `ch00-intro`：同一段落内若同时出现两词，应改用 `标定`。

### 4. `现场` 的另一种含义：工业装置现场（`ch01-c`）—— **不是 in situ，不得改**

`ch01-c`「与工艺表现互查」条目（约第 1027 行）有 2 处 `现场`：
「若**现场**表现为『压降快速上升』而实验室磨耗率很低，应反过来怀疑取样位置
（**现场**碎粉来自床层上部或运输环节）」。这里指**工业装置现场**，与 in situ／operando
无关——**改成 `原位` 会制造真正的语义错误**。上面「原位／现场」的裁定只覆盖
「in situ 的旧译」这一个义项；全书再扫 `现场` 时若命中此类用法，一律保留。

## 三、复现方式

```
python tools/check_terms.py     # 扫描，输出 tools/term_audit.txt
python tools/fix_terms.py       # 施加已裁定的统一（幂等，可重复运行）
```

注意：控制台是 GBK，**不要**用 `python ... | Out-File` 收集中文输出——
Python 会先按 GBK 转码，存成 UTF-8 后中文永久损坏。工具已改为自己写 UTF-8 文件。
