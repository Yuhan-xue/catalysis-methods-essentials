（公式登记表，面向分片作者提出的存疑清单）分工不同：本表面向**已经落到 tex 里的
核对结论**，逐条给出「哪一页图像、看到了什么、判决是什么」，使任何一条「已核对」

## 二、方法与判定词汇

### 方法

1. 用分片首部注释或 `\src{...}` 行确定「书内页 / PDF 页」映射
   （上册 书内 = PDF − 19；下册 `off` 随分片不同，见各分片首部注释）。
2. 渲染页面图像：
   ```powershell
   python tools/vpage.py up   <PDF页序> build/verify/pages/u<页>.png --dpi 190
   python tools/vpage.py down <PDF页序> build/verify/pages/d<页>.png --dpi 190
   # 需要辨认单个下标时窄幅高倍：
   python tools/vpage.py down 246 build/verify/pages/d246_nt2.png --dpi 500 --top 0.085 --bottom 0.20
   ```
3. 用 `read_image` **本人读图**，逐字符转录原书印法；OCR 文本（`sources/parts/*.txt`）
   **只用于定位**，不作为形式依据。
4. 与草稿对照后给出判决并回填本表；判决为「已核对并修正」的，同步改 tex。

### 判定词汇

| 词汇 | 含义 |
|---|---|
| `已核对一致` | 原书印法与草稿形式一致（含互为倒数、移项等等价写法，需注明等价关系） |
| `已核对并修正` | 读图后发现草稿有误，已按原书改正 |
| `形式一致但符号不同` | 数学内容一致，仅记号习惯不同（需注明两套记号的关系） |
| `原书自身问题` | 原书印刷/推导自身有误或不自洽；草稿按自洽形式写，并在正文注明 |
| `改编补充` | 原书无此内容，属改编新增；已在正文注明 |
| `未覆盖` | 尚未读图核对，**不得**视为通过 |

**纪律**：没有真正读到页面图像的条目一律写 `未覆盖`；
`\tocheck` 清零 ≠ 已核对（见第五节 ch07-a 例）。

### 证据文件

- 页面图像：`build/verify/pages/`（96 张 PNG）
- 全部 PNG 的字节数与 SHA-256 清单：`build/verify/pages_sha256.txt`
  （格式 `文件名|字节数|SHA256`，可 `Get-FileHash` 复算）
- 注意：`down043_250.png` 与 `down043_251.png` 字节完全相同
  （697450 B，SHA-256 `1774E6494DE7A52729ADDCB6068C3363D27B9D609D1A256D7F25DEDEDA19F5DB`），
  是同一页的重复渲染，引用时只算一条。
